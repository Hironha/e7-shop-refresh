# E7 Shop Refresher

A simple script to refresh Epic Seven secret shop using computer vision algorithms.

## Usage

For now, to use the script make sure you have [uv](https://docs.astral.sh/uv/) and [python](https://www.python.org) installed. Then, setup the environment with project dependencies:

```sh
uv sync
```

and run the script using:

```sh
uv run ./src/main.py
```
